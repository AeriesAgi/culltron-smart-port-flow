# Smart Port video demo script

1. Landing: show enterprise AI story and app-first driver loop.
2. Control room: show queue pressure, disruption feed, Gemini/fallback status and recommended next action.
3. Execution plans: generate, approve and dispatch a plan.
4. Fleet owner: open `/fleet`, then `/fleet/tracker` for map-style truck check-ins.
5. Driver Companion: open `/driver-app`, send GPS/demo check-in, report action, ask Copilot.
6. Tracker update: return to `/fleet/tracker` and truck detail to show latest check-in/audit.
7. Gemini: generate an operations brief and explain model/fallback badge.
8. Emissions: show idling/CO₂ reduction estimate.
9. Close: enterprise readiness, connector-ready architecture and honest demo limitations.
