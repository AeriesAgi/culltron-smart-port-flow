# Demo Script

1. Start on `/` and explain the closed loop: control room → Gemini agent → execution plan → fleet owner → driver app/WhatsApp → audit → emissions impact.
2. Use `/demo-access` and choose Judge Demo.
3. Open `/demo-tour` for the guided route.
4. Open `/gemini-agent`, show readiness and generate an operations brief.
5. Open `/agent-governance`, run safety checks for safe, approval-required and blocked requests.
6. Generate `/execution/plans`, open a plan and truck `SPQ-2026-0042`.
7. Open Fleet Tracker, request an app check-in, use the Driver Companion App/web companion to send status and location/check-in, then show notification/timeline updates.
8. Open `/enterprise-readiness` and describe pilot path plus production hardening.
