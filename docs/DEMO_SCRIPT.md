# Smart Port Demo Script

1. Open `/` and state that Smart Port is a prototype using synthetic demo data and connector-ready architecture.
2. Open `/demo-access`, choose Judge Demo, and continue to `/demo-tour`.
3. Open `/dashboard` for the Port Admin command centre.
4. Open `/gemini-agent`, generate a Gemini Operations Brief or fallback brief, and point out human approval and audit history.
5. Open `/execution/plans`, generate a plan, and open a plan detail.
6. Open `/fleet/trucks/SPQ-2026-0042`, request location, send demo WhatsApp, and move the truck to staging or release to gate.
7. Open `/driver/demo`, confirm an allowed action, and show the status timeline.
8. Open `/fleet/notifications`, then `/reports` and `/enterprise-readiness`.

No live Transnet/IPMS/customer integration is claimed during the script.
