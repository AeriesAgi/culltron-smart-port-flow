# Gemini Agent Award Notes

The Gemini Operations Agent is the flagship console at `/gemini-agent`.

It shows readiness, operational inputs, workflow trace, action generators, Gemini-vs-fallback comparison, audit history and fallback safety. Actions include operations brief, fleet owner plan, driver brief, disruption recovery, emissions impact, executive judge summary, governance review and pilot readiness brief.

If Gemini is not configured, the page still works and displays deterministic fallback status.
